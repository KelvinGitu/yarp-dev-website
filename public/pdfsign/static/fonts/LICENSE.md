# Fonts

Bundled so pdfsign never fetches anything from the internet. Latin (and, where
the face has one, extended Latin) subsets in WOFF2, from Google Fonts via
Fontsource.

| Family | Used for | License |
|---|---|---|
| Schibsted Grotesk | The interface | SIL Open Font License 1.1 |
| Caveat | Typed signatures | SIL Open Font License 1.1 |
| Herr Von Muellerhoff | Typed signatures | SIL Open Font License 1.1 |
| Mrs Saint Delafield | Typed signatures | SIL Open Font License 1.1 |
| Homemade Apple | Typed signatures | Apache License 2.0 |

Both licenses allow bundling these fonts with software, and embedding them in
what it produces (here, a typed signature drawn into a PDF as an image).
