    Your phone needs to be on the same wifi as this computer. The code works once and expires after 10 minutes.

    The first time, Windows asks whether pdfsign may use your network. Allow it on private networks: pdfsign opens the connection only while this code is showing, and your phone can reach nothing but this signing page.
